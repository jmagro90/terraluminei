## Publicar no GitHub Pages

1. Extraia o ZIP.
2. Entre no repositório `terraluminei`.
3. Apague os arquivos antigos ou substitua pelos novos.
4. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
5. Confirme o commit.
6. Em **Settings > Pages**, escolha:
   - Branch: `main`
   - Folder: `/(root)`
7. Salve.

O endereço esperado será:
`https://jmagro90.github.io/terraluminei/`
